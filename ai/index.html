AI Agent 实战

AI Agent（智能体）是 FDE 手里最重要的武器：能在客户现场快速搭建、稳定运行的 Agent 系统，就是前沿部署的核心交付物。

这一目录是 Agent 工程的中文整理——概念与架构、框架选型、从 RAG 到护栏的落地知识系列。上手顺序建议：先读《AI Agent 入门指南》建立概念，再按《工程师转 AI，别从模型开始》的五步路线推进。

下面的清单是本目录的全部记录。

AG-14 提示词注入攻防：不可信内容的安全边界 Prompt Injection 是 AI 应用特有的攻击面：四类注入入口、三层防御（指令数据分离/权限最小化/输出管控）与红队测试方法。 2026-11-05 AG-06 上下文工程：比提示词更重要的手艺 上下文窗口是 AI 应用的内存：四个内容来源的优先级、压缩手法、反模式，以及和提示词工程的区别。 2026-11-05 AG-02 工程师转 AI，别从模型开始，从 Agent 开始 给要转 AI 的工程师：为什么「先去学模型」是低效路线，而 Agent 工程是复用率最高的切入点——三个论据、一条五步路线和常见误区。 2026-11-05 AG-07 多智能体：什么时候真的需要多个 Agent 先泼冷水再讲拓扑：单 Agent 能覆盖的场景远比想象多，真正需要拆分的三个信号、三种常见拓扑与成本账。 2026-11-05 AG-08 Tool Use：把模型变成系统的一部分 工具调用的机制与 schema 设计原则、错误回传自纠、幂等与副作用控制、注入风险——工具设计的四条军规。 2026-11-05 AG-11 Token 经济学：AI 应用的成本控制 把 token 当预算管理：五个降本杠杆（缓存、模型路由、批量、上下文瘦身、蒸馏），先度量再优化的顺序，和不该省的地方。 2026-11-05 AG-04 RAG 入门：让模型答对它没学过的知识 RAG（检索增强生成）的完整管线、五个最常见的坑和各自的修法，以及判断一个 RAG 系统能不能上线的标准。 2026-11-05 AG-12 RAG 进阶：混合检索、重排与切分策略 把 RAG 从「能用」推到「准」：切分的父子块策略、BM25+向量+RRF 混合检索、重排模型、检索层单独评估与查询改写。 2026-11-05 AG-03 MCP：让 AI 接上你的系统 MCP（Model Context Protocol）是什么、解决什么集成问题、三层架构与三类原语，和一个最小可运行的代码示例。工程师视角，五分钟读完。 2026-11-05 AG-10 LangChain / AutoGen / CrewAI 怎么选 主流 Agent 框架横评：先决定要不要框架，再看三家各自的强项与代价，附场景决策表和一条保命原则。 2026-11-05 AG-09 Guardrails：给 AI 上安全带 AI 应用上线前的四道防线：输入过滤、提示注入防御、输出校验、人工确认——每道防线管什么风险，附检查表。 2026-11-05 AG-05 Evals：AI 应用的质量底座 为什么没有评估集的 AI 应用永远停在 Demo：三类评估、测试集怎么建、用什么指标、如何接进 CI。 2026-11-05 AG-13 Agent 工程师面试题库：考点与参考回答 Agent/AI 应用工程师岗位的高频面试题，按原理、工程、场景、开放四组整理，每题给考点与回答要点——可用于面试准备与自我检验。 2026-11-05 AG-15 Agent 的记忆系统：记住该记的，忘掉该忘的 记忆不是把历史全塞进窗口：三类记忆（会话草稿/结构化事实/长期检索）、记住什么忘掉什么的判断标准、以及记忆效果的评估方法。 2026-11-05 AG-01 AI Agent 入门指南：从概念到实战 什么是 AI Agent？它和普通 AI 对话有什么不同？这篇文章帮你理清概念，并带你用 LangChain 搭建第一个 Agent。 2026-09-01
