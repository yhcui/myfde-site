## 我是谁

## 技术栈

**Java 后端**：多年生产经验。Spring Boot、微服务架构、高并发系统设计、消息队列与缓存等常用中间件。工程纪律与线上意识是这段经历给我的底色。

**Python Agent**：当前主攻方向。LangChain、AutoGen、CrewAI 等框架，RAG 与向量数据库，LLM API 应用开发，FastAPI 服务搭建。做过知识库问答、客服 Agent 等真实场景，完整记录在 [AI Agent 实战](/ai/)。

**Web3**：智能合约开发、DApp 构建、DeFi 协议理解。这段经历让我习惯从零理解一个新领域——和 FDE 驻场要干的事本质相同。
